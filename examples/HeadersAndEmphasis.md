## Emphasis
* **b()** renders **bold text**
* **i()** renders _italic text_
* **s()** renders ~~strikethrough text~~
* **ic()** renders `inline code`

### cb() for a fenced code block, with an optional language for syntax highlighting
```js
function greet(name) {
  return `Hello, ${name}!`
}
```
Without a language, `cb()` still renders a plain fenced block:
```
No syntax highlighting here.
```
